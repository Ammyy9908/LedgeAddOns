# Changelog

Newest version first. Every new `version` in addon.json needs an entry here.

## 0.2.0

- Categories: in Ledge 0.1.0 Beta 8 or later, pick Applications, Files or Settings to search only those. Files
  lists what you opened in the last two weeks before you type, and shows when each file was last opened.

## 0.1.0

- Search apps, System Settings pages and files in the home folder from Ledge's launcher, with answers as you type:
  sums, percentages and tips, unit conversions and times in other cities. The last row searches the web.
- Ask AI with your own key, for Claude, ChatGPT, Gemini or any OpenAI-compatible server. The key stays in the
  Keychain and a question is sent only when you choose its Ask row.
