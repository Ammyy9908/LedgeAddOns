# Changelog

Newest version first. Every new `version` in addon.json needs an entry here.

## 0.1.1

- Shows each transfer beside the notch while it runs: the device, how much has gone, and a progress ring, then how
  it ended for a few seconds.

## 0.1.0

- Send files and folders to nearby LocalSend devices: drop them on a device in the notch, or Send with LocalSend on
  a shelf item.
- Receive from them: accept in the notch, saved to Downloads, Desktop or Documents and put on the shelf.
- HTTPS with pinned certificates, an optional PIN, and discovery by multicast with a network scan as fallback.
