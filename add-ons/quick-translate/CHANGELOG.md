# Changelog

## 0.1.0

- Translate selected text using Apple Translation on this Mac, in a floating card beside the selection.
- Choose target and second languages, and assign a translation shortcut in Ledge settings.
- Copy the result or safely replace the original editable selection after reviewing it.
- Optionally show a Translate button after mouse selections; it starts off.
- Exclude secure fields and oversized selections, and explain unavailable language pairs and permissions.
