# Changelog

Newest version first. Every new `version` in addon.json needs an entry here.

## 0.1.0

- Uninstall an app with the files it left in your Library: choose it, drop it on Uninstall, or send it from the shelf.
  Files named after its identifier start checked, ones that only share its name start unchecked.
- Clean up storage: app caches, logs, Xcode build data, device support files and developer caches.
- Everything goes to the Trash, and Put Back returns the last move.
- Scheduled cleaning, weekly or monthly, of caches and logs unused for three days, leaving open apps' alone.
