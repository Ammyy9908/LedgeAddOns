# Changelog

## 0.1.0

- Added a basic keypad and two banks of scientific functions, with degree and radian modes.
- Added typed expression previews, percentages, powers, factorials and scientific notation.
- Added copyable results, session memory and a 50-entry local calculation history with restore.
- Added a compact result widget, an opening shortcut and saved preferences.
- Kept calculations usable when copying or notch-opening permission is disabled.
