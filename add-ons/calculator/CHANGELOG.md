# Changelog

## 0.2.0

- Added a full 10 × 5 scientific keypad beside the number pad, orange operators, selected modes and a large right-aligned result.
- Added inline expression entry with Return to evaluate, native button feedback and a pin control.
- Matched the Mac Calculator's Delete/AC and sign/zero key positions; regression-tested Settings, widget, shortcut and History return paths.
- Scientific functions operate on the current expression, with inverse functions in the second bank.
- Requires the new LedgeKit 0.23.0 native page controls and an updated Ledge host.

## 0.1.0

- Added a basic keypad and two banks of scientific functions, with degree and radian modes.
- Added typed expression previews, percentages, powers, factorials and scientific notation.
- Added copyable results, session memory and a 50-entry local calculation history with restore.
- Added a compact result widget, an opening shortcut and saved preferences.
- Kept calculations usable when copying or notch-opening permission is disabled.
